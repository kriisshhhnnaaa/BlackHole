# Black Hole

An interactive 3D black hole observatory built with React, Three.js, and Vite.

Explore the event horizon, watch the accretion disk evolve, bend simulated light with the lensing control, and interact with objects in the gravity lab. Asteroids and other test bodies can be spawned, selected, dragged, released, and followed as they orbit, escape, or cross the illustrative capture boundary.

## Run locally

```bash
npm install
npm run dev
```

Then open the local address shown by Vite.

## Build

```bash
npm run build
```

The gravity and lensing views are educational visual approximations using normalized simulation units.
